# 《面向图应用的系统设计》通读问题清单

> **讲课对象**：计算机专业一年级研究生（具备 CSAPP / 计算机体系结构基础）
> **讲稿规模**：109 张幻灯片，约 1580 行 markdown
> **覆盖范围**：图应用背景 → 图处理系统 → 时序图存储 → 图表示学习与随机游走 → 知识图谱 → LLM + KG → 实践作业
> **复盘时间**：2026-09-05（前一轮已完成排版修复，本轮为逻辑/内容/衔接的问题汇总）

按严重度分三档：
- 🔴 **必修**：影响学生认知连贯性、出现硬伤
- 🟡 **应修**：影响可读性/可懂性，不修会让学生走神
- 🟢 **可修**：锦上添花，做完后讲稿更精炼
