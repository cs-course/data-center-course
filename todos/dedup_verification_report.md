### 5.4 ⚠️ 版面溢出风险：OS 分流片

**问题描述：** OS 三张分流片（A/B/C）使用了以下样式：

```css
p { padding-top: 560px; font-size: 22px; }
blockquote { font-size: 19px; color: #666; }
```

每片包含两个块级元素：一个 `<p>`（结论句）和一个 `<blockquote>`（去向标注）。两者都会应用 `padding-top: 560px`，导致：

- `<p>` 被推到图片下方合适位置
- `<blockquote>` 被 `<p>` 进一步推到更下方

**渲染验证：** 将分流片 A 渲染为 PNG 后确认，blockquote 的去向文字紧贴幻灯片底边，部分可能被裁切（取决于播放器/导出器的溢出策略）。

**修复建议：** 将 blockquote 的去向标注合并到 `<p>` 元素内（用 `<br>` 换行），或去掉 `p { padding-top }` 改用 `section { padding-top }` 并让 p/blockquote 正常流式排列。
